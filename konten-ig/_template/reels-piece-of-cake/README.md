# Template Reels ExtraCourse (Piece of cake, 28 Okt 2026)

- reel.html: animasi 1080x1920, fungsi render(t) murni dari waktu t. Ketukan musik B(k) = 0.39 + 0.6735*k (89 BPM).
- make.py: render 60 fps lewat Playwright lalu dihaluskan ke 30 fps (motion blur), digabung dengan mix.wav.
- mix.py: musik + efek suara per momen ketukan.

Aset yang dibutuhkan (tidak disimpan di repo):
- render/logo.png dan render/logo-light.png: ada di kanvas desain "Gaya Visual Feed ExtraCourse".
- render/gf/ofl/...: font Plus Jakarta Sans dan DM Serif Display dari repo google/fonts.
- music.mp3 dan sfx/*.mp3: folder Google Drive "MUSIC FOR IG" (musik Kiravale "Funny Music" dari Pixabay).
